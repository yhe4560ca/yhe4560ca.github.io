1. Purpose

This SOP describes how to process outbound orders in the warehouse management system (WMS), from receiving through picking and packing.

2. Scope

This SOP applies to all warehouse staff who use the WMS to receive, pick and pack orders.

3. Definitions

TermDefinition
WMSWarehouse management system
PLPicking list: a document listing the orders and items to be picked
One ticket, one itemAn order that contains a single item
One ticket for multipleAn order that contains more than one item

4. General system use

4.1 Loading data

When a module is opened from the left menu, the WMS displays No data available until data is requested. This does not mean there are no records.

To load data, click Inquiry.

5.2 Shipping

5.2.1 Create a picking list

  1. In the left menu, select Outbound management → Create a picking list.
  2. Click Inquiry to load the orders.
  3. Check the Type of picking column. Each order is classified as One ticket, one item or One ticket for multiple.
  4. Create a separate picking list for each type.

5.2.2 Print a picking list

  1. In the left menu, select Picking list.
  2. Click Inquiry to load the picking lists.
  3. Locate the picking list by its PL number (see section 5.2.3).
  4. Select the picking list and click Print.

    Note: The WMS does not display the PL number after a picking list is created, and the included orders are removed from the Create a picking list screen. Find the new list on the Picking list screen.

5.2.3 Picking list numbering

PL numbers use the format: PL + YYMMDD + three-digit sequence number.

The date in the PL number is the day after the creation date.

Created onPL numbers
10/14/26PL261015001, PL261015002, …

5.2.4 Packing

  1. In the left menu, select Outbound management → Package management, then select the page that matches the picking list type: One ticket, one item or One ticket for multiple.
  2. In Picking order number, enter the PL number and click Search.

    Note: A packaging material pop-up may appear when you resume packing a picking list. See section 6.1.

  3. Select the Print labels check box.
  4. Scan the SKU of an item. The shipping label prints.

    Note: If no label prints, see section 6.2.

  5. Wait until the label has printed before you scan the next item.

Caution: Scanning the same SKU in quick succession can print duplicate shipping labels.

6. Known issues

#IssueWorkaround
6.1When you resume packing a picking list, a pop-up may ask you to select packaging material. The selection cannot be skipped. One ticket, one item orders do not require packaging material.Select the smallest packaging material (usually the first option) to continue.
6.2No shipping label prints after an item is scanned. The order may not have a shipping label, or printing failed for another reason.Write down the order details and report them to your supervisor.
