# yheca Public Tools

Static, browser-only tools hosted via GitHub Pages. No build step, no backend — open the HTML files directly or via the links below.

**Public URL:** https://yhe4560ca.github.io/

## Tools

- [Bin Label Generator](https://yhe4560ca.github.io/tools/bin-label-generator.html) — printable 6x4 warehouse bin labels.
- [Pallet Info Label Generator](https://yhe4560ca.github.io/tools/pallet-info-generator.html) — printable portrait 4x6 pallet labels.
- [WO Bin Label Generator](https://yhe4560ca.github.io/tools/wo-bin-label-generator.html) — printable 4x6 barcode labels for work-order bins.
